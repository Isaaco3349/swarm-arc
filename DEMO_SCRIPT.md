# Demo Script (target: under 3 minutes)

**Goal:** show the full loop — hiring, bonded trust, real settlement, and a real creator getting paid — in one continuous take.

1. **0:00–0:20 — The problem, fast.**
   "Agents can call each other, but they can't hire each other — no pricing, no trust, no rail cheap enough for a two-second task. Swarm fixes that."

2. **0:20–0:50 — Show the bonded providers.**
   Open the dashboard. Three provider agents listed, each with a USDC bond and reputation score. Point out one is a creator-proxy agent representing a real person.

3. **0:50–1:30 — Post a task, watch the match + payment.**
   Trigger a task from the requester agent live. Show the matcher picking the highest-reputation eligible provider. Show the USDC payment settle on Arc — pull up the explorer/tx hash on screen.

4. **1:30–2:10 — Show the creator getting paid.**
   Post a second task specifically routed to the creator-proxy agent. Show the payment landing in a wallet that's visibly tied to a real person, not a pooled treasury.

5. **2:10–2:40 — Trigger a slash.**
   Post a task to an agent you've rigged to underdeliver. Show the bond visibly decrease on-screen the moment the outcome resolves — no manual dispute, it's automatic.

6. **2:40–3:00 — Close.**
   "That's Swarm: agents that hire, get hired, and have something to lose when they don't deliver — and real people getting paid at the other end of it."

## Notes
- Record the transaction hashes / wallet balances changing live — don't fake or pre-render this part, judges read the repo and may try the live link themselves.
- Keep narration plain; let the on-screen numbers do the convincing.
